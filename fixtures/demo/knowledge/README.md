# Knowledge base

Drop documents here (Markdown, Word, PDF, PowerPoint). They are indexed with SQLite full-text search
and retrieved into each solution's Context Pack as `K#` facts that agents can cite.

Good things to add:
- Competitive intelligence (one file per competitor), for example exports from Klue or Crayon.
- Persona and segment research.
- Examples of strong past collateral.
- Customer voice: Gong call notes, win/loss interviews.
- Fact sheets and approved proof points.

> The files shipped in this folder are ILLUSTRATIVE SAMPLES for the POC. Competitor names
> (Northwind CX, Contoso Contact, Fabrikam Engage) are fictional placeholders.
